# Portfolio cá nhân

Portfolio tĩnh được xây dựng bằng HTML, CSS và JavaScript thuần, không cần cài thư viện.

## Chạy trang web

Mở `index.html` trực tiếp trong trình duyệt. Nếu dùng VS Code, có thể chạy bằng tiện ích Live Server.

## Cá nhân hóa

- Thay tên, vai trò, phần giới thiệu, kỹ năng và nội dung dự án trong `index.html`.
- Cập nhật email, liên kết GitHub/LinkedIn và thay ảnh chân dung mẫu bằng ảnh của bạn.
- Chỉnh màu sắc, font chữ và bố cục trong `styles.css`.
